\# 🛒 ShopEZ - MERN Stack E-Commerce Application



ShopEZ is a full-stack e-commerce web application built using the MERN stack.



It allows users to browse products, manage their shopping cart, place orders using Cash on Delivery or Razorpay online payment, and track their orders.



It also includes an admin dashboard for managing products, users, and orders.



\---



\## 🚀 Features



\### 👤 User Features



\- User registration and login

\- JWT authentication

\- Browse products

\- Search and view product details

\- Add products to cart

\- Increase/decrease product quantity

\- Remove products from cart

\- Clear shopping cart

\- Checkout

\- Cash on Delivery

\- Razorpay online payment

\- Payment verification

\- View order history

\- View order details

\- Cancel eligible orders

\- Product reviews and ratings



\---



\## 👨‍💼 Admin Features



\- Admin authentication

\- Admin dashboard

\- View total users

\- View total products

\- View total orders

\- View total sales

\- Manage products

\- Manage users

\- View all orders

\- Update order status

\- Monitor cancelled, pending and delivered orders



\---



\## 💳 Payment Methods



ShopEZ supports:



\- Cash on Delivery (COD)

\- Razorpay Online Payment



Razorpay payment verification is performed securely on the backend using the Razorpay signature.
